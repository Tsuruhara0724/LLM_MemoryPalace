# Vocabulary Audit

Last verified: 2026-07-02

## Selection policy

- Use basic-level, everyday nouns rather than named subtypes.
- Avoid words whose meaning changes when only the grammatical gender/article changes.
- Keep correct Spanish accents.
- A masculine/feminine person pair is acceptable if it describes the same role.

## Changes in this audit

- `concha` (shell) -> `flor` (flower): replaced with a broader, basic-level noun.
- `cometa` (kite) -> `nube` (cloud): removed because `el cometa` means comet while `la cometa` means kite.
- `mascara` -> `máscara`: corrected the noun's written accent.

## Gender-meaning result

After replacing `cometa`, no current item has the target meaning determined solely by switching between `el` and `la`.

Items still worth contextual monitoring are `vela` and `llave`, because they are polysemous even though their grammatical gender does not select the intended meaning. The local image and English gloss currently disambiguate them.
