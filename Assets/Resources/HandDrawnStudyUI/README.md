# Hand-Drawn Study UI

Base textures for the participant-facing PC setup screens.

- `wood_desk_background.png`: full-screen background image.
- `paper_panel.png`: paper panel background. Set the Sprite Editor border before using it as a 9-sliced UI Image.

Use Unity UI colors for selected tabs, button states, and condition choices so the visual language stays consistent without creating separate image assets for every state.
